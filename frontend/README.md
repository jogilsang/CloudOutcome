# CloudOutcome frontend

React/TypeScript/Vite, bilingual banana UI. See SPEC.md, SECURITY.md and AGENTS.md.

```sh
npm ci
npm run dev
npm run build
npm run build:preview
npm test
python3 tools/check_policy.py
```

Local development proxies `/api` to the separately running backend (`../backend/tools/dev.sh --profile <aws-profile>` enables the live AWS estimate tab locally). `preview/CloudOutcome.html` is an explicitly isolated synthetic offline sample. A normal production build requires `/config.json` generated by the deployment runner; it fails closed if config/login is unavailable. Cognito code + PKCE login keeps access tokens only in memory; reload requires login again (Cognito may reuse its session). No refresh token persistence.

CodePipeline consumes this repository's main source snapshot with backend and infra snapshots. It reuses the compiled bundle across dev/validation/prod, injecting public config only. Local artifacts and dependencies are ignored by Git. Source contract fixtures are synthetic and versioned. The current KPI data remains synthetic even in authenticated cloud mode.

Origin: CodeCommit `outcomelens-frontend` in us-east-1. Visitors start in the synthetic demo without signing in; `public/outcomelens-readonly-role.json` is the read-only account connection template served with the site. Feature branch -> local checks -> reviewed commit -> main push triggers automatic deployment once bootstrap is complete.

## Local source policy and CodeCommit push

`core.hooksPath=.githooks` is configured in this workspace; isolated clones can enable it with `git config core.hooksPath .githooks`. The pre-commit hook scans working and staged content for selected sensitive patterns. Review history and data semantics too; pattern scanning is not exhaustive. Unpublished agent commits were given pseudonymous author metadata before any remote push.

The CodeCommit origin selects your AWS CLI profile through `git-remote-codecommit` (`codecommit://<profile>@<repo>`). `tools/push.sh` pushes main with `AWS_PROFILE`; profiles created by `aws login` so install the helper with the CRT extra (`uv tool install git-remote-codecommit --with 'botocore[crt]'`). No static Git credentials were created.
