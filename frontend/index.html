CloudOutcome

What did our cloud spend actually buy the business? CloudOutcome answers that on one screen.

It connects AWS accounts through a read-only IAM role (cloud_outcome_readonlyaccess, with an External ID), measures real usage in Amazon CloudWatch across every enabled Region, prices it with the public AWS Price List API, and combines it with business inputs such as revenue and customer satisfaction. The result is storefront KPIs, KPI lineage from cost to KPI to tagged AWS resources, and a ranked list of today's actions. Costs are estimates from list prices, not a bill, so it also works where Cost Explorer is blocked.

What the demo shows

  • Executive summary - AWS cost vs. IT budget, KPIs on target, storefront health with 7-day trends, today's actions.
  • Business KPIs - per-storefront KPIs that mix manual inputs with CloudWatch values, plus a KPI builder.
  • KPI lineage - company goal, storefront KPIs and the AWS resources tagged outcome behind them.
  • Live AWS estimate - services in use across all Regions and per-resource cost estimates; connect up to 100 accounts.
  • KPI studio and export - ranked KPI picks for a situation; JSON, HTML report or PDF.

The demo company santacloth is fictional, but its three storefronts (kids, adult, senior) run on real Amazon API Gateway, AWS Lambda and Amazon DynamoDB resources with synthetic orders every five minutes.

Built on AWS

AWS Amplify Hosting, Amazon API Gateway, AWS Lambda (FastAPI), Amazon DynamoDB, Amazon Cognito, Amazon EventBridge, Amazon CloudWatch, AWS Price List API, AWS CodeCommit, AWS CodePipeline, AWS CodeBuild, AWS CloudFormation (CDK) and AWS CodeDeploy canary releases. Built with coding agents Codex (Amazon Bedrock) and Claude Code.
